## `$ ls ~/projects`

| Repo | What it is |
|------|------------|
| [`swarmlabre`](https://github.com/virqdroid/swarmlabre) | An LLM agent swarm for static malware analysis. Up to six agents work one ELF, PE or APK and post to a shared board. The board checks every finding against the file's bytes and the tool log, and a finished run replays offline to byte-identical reports. Agents run in network-less containers. Python, with a vanilla JS UI. Alpha, MIT. |
